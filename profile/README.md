## 🧠 Overview

**DroidCam** transforms a compatible smartphone camera into a webcam that can be used with a Windows computer. By pairing the mobile application with its desktop client, users can bring the camera hardware of their phone into video calls, streaming setups, recording applications, and other software that accepts webcam input.

The connection can be established through Wi-Fi or USB, giving users flexibility when setting up their workspace. Once connected, the phone can provide video to supported desktop applications, while compatible configurations can also make the phone's microphone available as an audio input.

DroidCam is particularly useful when a dedicated webcam is unavailable or when users want greater flexibility over camera placement. Depending on the device and configuration, the software provides options for image adjustments, camera controls, resolution settings, and integration with applications such as Zoom, Discord, Microsoft Teams, and OBS Studio.

## Additional Information for Windows Users

**DroidCam** uses two connected components: the mobile application captures video from the phone, while the Windows client receives the stream and makes it available as a webcam source. After pairing the devices, compatible applications can select the DroidCam video feed in the same way they would select a conventional camera.

A wireless setup is convenient for flexible camera positioning, while USB can provide an alternative connection when network conditions are unsuitable. For Wi-Fi operation, the phone and computer generally need to be reachable on the same local network. USB configurations may require additional device setup depending on the smartphone.

The software can fit into a variety of Windows workflows, including online meetings, remote teaching, live broadcasting, video recording, and content creation. Users can also take advantage of supported image controls and OBS integration to build a more customized camera setup around an existing smartphone.
